    Mi a dewyhider?What is dewyhider?

    A dewyhider (DewyHider) LuckPerms csoportokhoz köti a parancsok láthatóságát és használatát. Rangonként állíthatod, mi jelenik meg tab-complete-ben és mi futtatható.

    • Whitelist mód — csak a listában lévő parancsok engedélyezettek / láthatók
    • Blacklist mód — a listában lévő parancsok rejtve / tiltva
    • Tab-complete szűrés és végrehajtás blokkolás
    • dewyhider.bypass — szabályok megkerülése

    dewyhider (DewyHider) ties command visibility and usage to LuckPerms groups.

    • Whitelist mode — only listed commands allowed / visible
    • Blacklist mode — listed commands hidden / blocked
    • Tab-complete filtering and execution blocking
    • dewyhider.bypass — skip rules

    Blacklist és WhitelistBlacklist and Whitelist

    A config.yml rules.groups szekciójában csoportonként választható whitelist vagy blacklist mód.

    • Whitelist — csak a megadott parancsok látszanak / futnak.
    • Blacklist — a listában lévők rejtve / tiltva, a többi szabad.

    Ha be van kapcsolva a use-highest-weight-group, a legmagasabb súlyú LuckPerms csoport szabályai érvényesek.

    In config.yml under rules.groups, each group can use whitelist or blacklist mode.

    • Whitelist — only listed commands are visible / runnable.
    • Blacklist — listed commands hidden / blocked; others allowed.

    With use-highest-weight-group, the highest-weight LuckPerms group rules apply.
